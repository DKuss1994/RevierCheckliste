# Patrol Checklist Manager

A backend system for the digital management of
security patrols and checklists.

Built with Java, Spring Boot and SQL –
as a replacement for error-prone Excel processes
in the security industry.

---

## The Problem

In many security operations, patrol data is still
managed manually in Excel spreadsheets.

This leads to:
- Inconsistent data due to manual entry errors
- Unclear responsibilities for special inspections
- No traceable history of completed patrols

---

## The Solution

This system centralizes the management of
checklists and patrol areas in a single
backend application.

Core features (Version 1):
- Management of patrol areas and checkpoints
- Automated activation and deactivation
  of special inspections
- Validation rules prevent incorrect entries
- 100+ unit tests secure the core logic

Planned (Version 2):
- PDF export of checklists
- Frontend interface
